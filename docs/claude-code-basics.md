# Claude Codeの仕組み: CLAUDE.md / Agents / Skills

Claude Codeは、ターミナルの中で動く「コードを読み書きできるAIアシスタント」。ファイルの読み書き・コマンド実行・GitHub操作などを、指示に応じて実際に行う。このリポジトリには、Claude Codeがこのプロジェクトを扱いやすくするための3つの仕組み(`CLAUDE.md`・Agents・Skills)が用意されている。それぞれ何のためにあるのかを説明する。

## CLAUDE.md — プロジェクトの「引き継ぎメモ」

[../CLAUDE.md](../CLAUDE.md) は、Claude Codeがこのリポジトリで作業するたびに自動的に読み込むファイル。新しく入ってきたメンバーへの引き継ぎメモのようなもので、次のようなことが書かれている。

- よく使うコマンド(`yarn dev`・`yarn test`など)
- このプロジェクト特有の注意点(例: 本番DBとローカルDBが分離されていない、Edge Runtimeの制約で`pg`が使えない、など)
- コードの全体構成
- Gitの運用ルール(ブランチの名前の付け方など)

これがあることで、**毎回同じ説明を繰り返さなくても**、Claude Codeが「このプロジェクトでは本番DBに気をつける必要がある」といった前提を最初から踏まえて動いてくれる。逆に言うと、CLAUDE.mdの内容が古くなる(実際のコードと矛盾する)と、Claude Codeが古い前提で判断してしまうので、大きな変更をしたときはCLAUDE.mdも合わせて見直すとよい。

## Agents — 特定の役割に特化した「担当者」

Agent(サブエージェント)は、特定の作業に特化した、いわば専門の担当者。通常のClaude Codeとの会話とは別に呼び出され、決められた役割だけをこなして結果を返す。このリポジトリには2つのAgentがある([../.claude/agents/](../.claude/agents/) 配下)。

| Agent | 何をする担当者か |
|---|---|
| `db-safety-guardian` | DBを触るコマンドを実行する前に、それが本番Neon DBとローカルPostgresのどちらに接続するかを確認し、危険なら警告する |
| `react-tutor` | 実装したコードに含まれるReact/Next.jsの概念を、学習者向けに噛み砕いて説明する(コードは変更しない) |

Agentは「レビューや判断が必要な作業」に向いている。たとえば`db-safety-guardian`は、コマンドを見て「これは安全か、危険か」を判断するという、単純な手順書には落とし込みにくい仕事をしている。

## Skills — 決まった手順を毎回同じようにこなす「作業手順書」

Skillは、決まった手順に沿って作業を進めるための、いわばマニュアル。Agentと違い「判断」よりも「手順の再現性」を重視する。このリポジトリには2つのSkillがある([../.claude/skills/](../.claude/skills/) 配下)。

| Skill | どんな作業手順か |
|---|---|
| `feature-branch` | Issueに対応する`feature/#<issue番号>`ブランチを作り、作業後に`Closes #N`を含むPRを作るまでの一連の流れ |
| `new-api-route` | 既存のAPI(`search`/`insert`/`update`/`delete`)と同じ書き方で、新しいAPIルートの雛形を作る |

「Issue #15の作業を始めたい」「新しいAPIルートを作りたい」のように頼むと、Claude Codeが該当するSkillを自動的に使う。毎回同じ手順を一から説明しなくても、リポジトリのルールに沿った進め方をしてくれる。

## Agent と Skill、何が違う?

| | Agent | Skill |
|---|---|---|
| 向いている作業 | 判断・レビューが必要なもの | 手順が決まっているもの |
| 例 | 「このコマンドは危険か?」を判断する | 「ブランチを切ってPRを出す」という決まった流れをこなす |
| コード変更 | するものとしないものがある(`react-tutor`はしない) | することが多い |

## まとめ

- **CLAUDE.md** = プロジェクトの前提知識をまとめた引き継ぎメモ(自動で読み込まれる)
- **Agent** = 判断が必要な特定の作業を任せる専門の担当者
- **Skill** = 決まった手順を毎回同じ形で実行するための手順書

いずれも「同じことを何度も説明しなくて済むようにする」ための仕組み。中身が気になったら、実際のファイル(`CLAUDE.md`・`.claude/agents/*.md`・`.claude/skills/*/SKILL.md`)を開いて読んでみてほしい。普通のMarkdownファイルなので、難しいものではない。
