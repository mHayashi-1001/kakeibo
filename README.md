## このプロジェクトで使っている技術

### フロントエンド

- React（UI ライブラリ）
- Next.js（React フレームワーク）
  動的なユーザーインターフェース

### ホスティング

- Cloudflare Pages（ホスティング）
  静的サイト配信

### API

- Cloudflare Functions（API エンドポイント/サーバーレス関数）
  サーバサイド処理

### バックエンド

- Prisma（ORM/データベース操作）
  TypeScript でデータベースを操作できる

### データベース

- PostgreSQL（データベース）
- Neon（サーバーレス PostgreSQL）
  サーバーレスで PostgreSQL サービスを使用できる
